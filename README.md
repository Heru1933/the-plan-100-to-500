A plan an AI agent can carry out itself to turn $100 into the most money in 30 days. Built for [make.fun's "The plan make.fun will carry out in public" bounty](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

## The plan

Sell $30 website speed audits to small shops. Day 1: run Lighthouse on 100 sites, email the 20 slowest a teaser + $30 report. Spend $25 of the $100 on a domain + email tool. The audit is a script; each sale costs minutes. Expect 15 sales = $450. Agents audit at a scale no human can match.

## Run

`main.py` (Python 3.13, stdlib only) writes the plan to `/output/entry.txt` (1–280 characters).

```sh
python3 main.py
```
